## 📖 نبذة عن الأداة / Overview

**ALOLL Gaming OS Toolkit** هي حزمة برمجية متطورة مصممة خصيصاً لمجتمع اللاعبين وصناع المحتوى بهدف تحويل نظام ويندوز العادي إلى بيئة ألعاب فائقة الأداء (Optimized Gaming OS). تعمل الأداة على تعطيل الخدمات الخلفية غير الضرورية، تحسين استجابة المعالج، تخفيض الـ Input Lag، واستقرار إطارات الألعاب (FPS Boost & 1% Lows).

**ALOLL Gaming OS Toolkit** is a specialized performance enhancement suite designed to transform standard Windows installations into a streamlined, high-performance gaming environment. By disabling unnecessary background telemetry, optimizing thread scheduling, and minimizing system input latency, it delivers higher and significantly more consistent frame rates.

---

## ✨ المميزات الرئيسية / Key Features

- 🎮 **تعزيز أداء الألعاب (FPS Boost)**: إزالة الاختناقات البرمجية في النظام لرفع معدل الإطارات وتحسين ثبات الفريمات.
- ⚡ **تخفيض زمن الاستجابة (Input Lag & Latency Reduction)**: تحسين توقيت استجابة الفأرة ولوحة المفاتيح والشبكة.
- 🛑 **تعطيل الخدمات غير الضرورية (Background Services Debloat)**: إيقاف الخدمات الثقيلة التي تستهلك موارد المعالج والذاكرة في الخلفية.
- 🧠 **تحسين استهلاك الرام (RAM Optimization)**: إدارة ذكية لاستهلاك الذاكرة العشوائية وتفريغ المساحات المهدرة.
- 🎛️ **خيارات تخصيص مرنة**: تفعيل وتعطيل التعديلات بضغطة زر واحدة مع واجهة رسومية سهلة الاستخدام.

## 💻 متطلبات النظام / System Requirements

- **نظام التشغيل / OS**: Windows 10 (20H2+) أو Windows 11 (64-bit).
- **الصلاحيات**: **تشغيل كمسؤول (Run as Administrator)** مطلوب لتطبيق تعديلات سجل النظام (Registry) وإدارة الخدمات.

---

## 🚀 طريقة الاستخدام / How to Use

1. حمّل ملف `ALOLL_Optimizer.exe` من قسم [Releases](../../releases) أو من هذا المستودع.
2. انقر بزر الفأرة الأيمن على الملف واختر **تشغيل كمسؤول (Run as Administrator)**.
3. يوصى بإنشاء نقطة استعادة (System Restore Point) قبل بدء التعديلات.
4. اختر الإعدادات والتعديلات المناسبة لنظامك ثم اضغط تطبيق (Apply).
5. قم بإعادة تشغيل الجهاز (Restart) لتطبيق التغييرات بنجاح.
